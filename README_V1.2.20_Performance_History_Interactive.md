# Website v1.2.20 — Performance History Interaction

## Change
- Made the Performance History range controls interactive.
- Clicking **1 MIN, 5 MIN, 15 MIN, 1 HR, 6 HR, or 24 HR** updates the graph immediately.
- The selected range updates the CPU average, peak, graph shape, and time-axis labels.
- Default remains **24 HR** to preserve the existing appearance.

## Scope
- Only the Performance History showcase was changed.
- Existing release, download, navigation, alerts, dashboard preview, developer, and footer components are untouched.
